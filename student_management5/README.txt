STUDENT MANAGEMENT SYSTEM - SCRUM, KANBAN AND XP

A beginner-friendly VS Code practical project.

FILES
1. index.html  - Complete Student Management System + Scrum + Kanban + XP + comparison
2. style.css   - UI styling
3. script.js   - Student registration/login/CRUD/search/report + Kanban board
4. agile.py    - Terminal output demonstrating Scrum, Kanban and XP
5. README.txt  - Instructions

BROWSER OUTPUT
1. Open the folder in VS Code.
2. Install Live Server extension.
3. Right-click index.html -> Open with Live Server.
4. Register a user and login.
5. Use Student System tab for CRUD operations.
6. Use Scrum, Kanban, XP and Comparison tabs for the Agile practical.

TERMINAL OUTPUT
Install Python 3 if necessary.
Open VS Code terminal:
    python agile.py

If that does not work on Windows, try:
    py agile.py

The terminal prints Product Backlog, Sprints, Daily Scrum, Sprint Review,
Retrospective, Kanban columns, XP practices and comparison.

IMPORTANT
Scrum, Kanban and XP are development methodologies. The application is the
same Student Management System; the difference is how the development work
is planned, tracked, tested and delivered.
