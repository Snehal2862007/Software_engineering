Part C: Extreme Programming (XP)


XP focuses on frequent delivery, customer feedback, testing and clean code.




Planning Game
Customer selects high-priority stories.


Small Releases
Deliver small working features frequently.


Pair Programming
Two developers work together on code.


Test-Driven Development
Write tests before or along with implementation.


Continuous Integration
Integrate and test code frequently.


Refactoring
